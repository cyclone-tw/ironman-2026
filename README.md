# 國小教師的 Agent OS：30 天讓 AI 的「做完了」有證據

2026 iThome 鐵人賽參賽系列 · 自我挑戰組

2026-09-11 開賽，每天一篇，連續三十天。

---

## 這個 repo 是什麼

我是國小教師，不是全職工程師。我沒有同事幫我 code review，沒有 QA，一開始也沒有 CI。
我只有一群 AI agent —— 而它們會告訴我「做完了」，即使其實沒做完。

這三十天要寫的，就是我怎麼被迫做出一整套機制，逼這些 AI 拿出證據來。

這個 repo 是這個系列的**證據存放處**：

- `posts/` —— 三十篇文章的原文
- `evidence/` —— 每一篇對應的可執行證據，你可以自己 clone 下來跑
- `scripts/` —— 我自己每天在用的兩支腳本，包含送出前的去敏閘門

## 為什麼要有這個 repo

因為一個標題叫「讓 AI 的做完了有證據」的系列，如果三十篇的證據全都是「相信我，我系統裡真的有」，
那它本身就沒有證據。

所以能公開的我盡量公開，能讓你自己跑的我做成腳本。

## 誠實說明

我的 Agent OS 主要程式碼在私有 repo（裡面有學校相關資訊和個人設定，不能公開）。
文章引用那些內容時，我會標明「以下為私有 repo 的去敏後節錄」，並盡量把可驗證的部分
重做成 `evidence/` 裡能獨立執行的最小範例。

哪些證據是一手的、哪些是我事後的敘述，我會在每篇文章裡分清楚。
