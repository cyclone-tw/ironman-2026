# Day 01 證據

> 我是國小教師，我有五個 AI 同事，它們會說謊

## 這裡有什麼

Day 01 是開場立論篇，沒有可執行的程式證據。

三個開場案例的完整技術記錄在私有 repo 與私有知識庫，文章中引用的是去敏後節錄。
從 Day 03 開始會有讀者可以自己重現的證據。

## 這個系列的證據原則

| 層 | 來源 | 讀者能做什麼 |
|---|---|---|
| 一手 | GitHub issue／PR／CI | 看時間戳與往返紀錄 |
| 二手 | 我事後寫的復盤 | 看根因分析與當時判斷 |
| 可執行 | 本 repo `evidence/` | 自己 clone 下來跑 |

每篇文章會標明用的是哪一層。
